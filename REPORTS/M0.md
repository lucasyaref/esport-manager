# M0 — Project skeleton — Report

## What changed
- **Godot 4.7.1 stable** installed at `~/Applications/Godot.app` (project targets 4.7).
- Godot project created: `project.godot`, main scene, folder structure `sim/` `game/` `data/` `tools/` `REPORTS/`, `.gitignore`.
- **`sim/rng.gd` (SimRNG)** — the one seeded RNG every future sim system must draw from. Helpers: `chance`, `pick`, `weighted_index`, `shuffle`. Tracks a draw counter that gets stamped onto every sim event, so any future determinism break is pinpointed to the exact draw.
- **`sim/sim_match.gd` (SimMatch)** — deterministic tick loop (10 ticks/sim-second), pure GDScript, no scene dependencies. M0 stub world: 10 placeholder entities drift to map center and resolve coin-flip "skirmishes". Output shape is the real one all later milestones build on: **setup in → ordered event stream + per-tick snapshots + MD5 checksum out**.
- **`tools/headless_run.gd`** — run one sim from the command line (`--seed=N --ticks=N --events`).
- **`tools/determinism_check.gd`** — runs 3 seeds twice each; same seed must be byte-identical, different seeds must diverge.
- **`tools/check.sh`** — the CI-style check (designer: you can ignore it). Lints `sim/` for global-RNG usage, then runs the determinism check.

## Determinism: verified, and the check already earned its keep
The first version of the check **failed** and caught a real bug: a GDScript trap where an unqualified `randf()` call inside our RNG wrapper silently bound to Godot's *global unseeded* RNG instead of the seeded one. Coin flips were nondeterministic; movement was fine, which made it subtle. Fixed, and the lint in `check.sh` now blocks that whole bug class in all future sim code. Current status:

```
ok   seed=1:         two runs identical, 18 events
ok   seed=42:        two runs identical, 19 events
ok   seed=987654321: two runs identical, 19 events
DETERMINISM CHECK: PASS
```

## What to look at in-game
Open the project in Godot and press **Play** (F5). You'll see the M0 placeholder screen: the determinism self-test result (two identical checksums, green PASS) and the stub event log rendered as a primitive kill feed. That's all M0 promises — dots don't move on screen yet; the visual map comes in M4.
